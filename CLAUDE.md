# Pills — генератор обоев

Статический сайт без фреймворков. Исходники в `src/`, сборка esbuild (`build.mjs`) → `dist/`.
Подробности структуры и команд — в README.md.

## Ветки и процесс
- **Вся работа ведётся в ветке `dev`.** Перед началом работы: `git switch dev`. Не коммить напрямую в `main`.
- `main` — продакшен. В неё попадает только готовое и проверенное: merge `dev` → `main` и push,
  когда пользователь явно скажет, что всё готово.
- Push в `dev` выкладывает превью на `dev.wallpaper-pills.pages.dev`,
  push в `main` — продакшен на `wallpaper-pills.pages.dev` (GitHub Actions, `.github/workflows/deploy.yml`).

## Перед коммитом
- `npm run build` должен проходить без ошибок.
- Проверить в браузере через `npm run dev` (http://localhost:8000), если менялся UI или рендер.

## Код
- Без зависимостей в рантайме: только ванильный JS (ES-модули) и CSS. esbuild — единственная dev-зависимость.
- `color.js`, `state.js`, `render.js` не трогают DOM (кроме `toCanvas`); весь DOM — в `main.js`.
- Формат ссылок-рецептов (параметры в hash) — публичный: не ломать обратную совместимость старых ссылок.
- Строки интерфейса — на русском.
